# Preferencias del usuario (definidas al iniciar el proyecto)

- **Paleta de colores**: borgoña (vino) y crema. El frontend debe usar esta identidad visual.
- **HTML base**: usar `docs/base-index.html` como punto de partida (no empezar de cero). Se puede modificar mucho, pero conserva la estructura de vistas (catálogo, libros, clientes, ventas, historial) con navegación por botones `data-target` y secciones `vista-*`.
- **Idioma de los artefactos**: español.
